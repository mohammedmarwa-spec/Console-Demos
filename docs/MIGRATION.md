# Repository migration

This project has moved from `design-police/design-police-playground` to **Aiven-Labs/console-prototype-lab**.

**New canonical URL:** https://github.com/Aiven-Labs/console-prototype-lab

## New clone

```bash
git clone git@github.com:Aiven-Labs/console-prototype-lab.git
cd console-prototype-lab
npm install
npm run dev
```

HTTPS:

```bash
git clone https://github.com/Aiven-Labs/console-prototype-lab.git
```

## Existing local clone

If you already have the old repo checked out:

```bash
git remote set-url origin git@github.com:Aiven-Labs/console-prototype-lab.git
git fetch origin
git checkout main
git pull origin main
```

## Access

Ask a teammate to add you to the **Aiven-Labs** GitHub organization if you cannot access the new repository.
